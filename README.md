# ESGSaathi Portal

Authenticated workspace: sign-in, dashboards, calculators, assessments, and admin.

This app is independent of the marketing site. After a user is verified, share this portal URL so they can sign in.

```bash
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001). Unauthenticated visits go to `/login`; after sign-in you land on `/user/dashboard`.
